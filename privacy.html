1. Scope & Purpose

Mister Studio Pro is a private, internal workflow and channel-operations tool used exclusively by the creator and owner of the connected channel UCkRLUtEP2CyoFtTWUiggMsg. The application is not publicly accessible, does not offer public registration, and does not collect or process data from external users or visitors to this informational website.

2. YouTube API Services & Authorized Data Accessed

Mister Studio Pro uses official YouTube API Services authorized via Google OAuth 2.0 by the channel owner. Specifically, when authorized, the client may access:

  • Upload & Channel Management Data: Video files prepared by the owner, video titles, descriptions, tags, thumbnails, and privacy/schedule settings published exclusively to the owner's channel.
  • Channel & Video Statistics: Public/owned channel counters (channel ID, title, view count, subscriber count) and per-video metadata and statistics (views, likes, comments, duration, publication status).
  • OAuth Credentials: OAuth 2.0 access and refresh tokens stored locally within the owner's private runtime environment strictly to maintain authorized API requests.

By accessing YouTube API Services through Mister Studio Pro, usage is also governed by the YouTube Terms of Service and the Google Privacy Policy.

3. How Data Is Stored, Used & Limited Use Compliance

  • API data and operational caches (such as video metadata and engagement metrics) are stored solely on the owner's private database and local environment to manage uploads and display operational analytics.
  • Data obtained through Google and YouTube APIs is used strictly to provide the owner's internal publishing and reporting workflow.
  • No Selling or Third-Party Sharing: Authorized Data is never sold, rented, licensed, transferred, or disclosed to third parties, never used for third-party advertising, and never used to train external or generalized AI/ML models.
  • Mister Studio Pro's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

4. Data Retention & Revocation of Access

Authorized API tokens and cached channel metrics are retained only while the owner actively operates Mister Studio Pro for channel management.

  • Revoking Access: The owner can revoke Mister Studio Pro's access to Google/YouTube data at any time via the Google Security Settings (Third-party apps with account access) page.
  • Deletion: Upon disconnection or deletion request, locally cached OAuth credentials and stored API metadata are deleted immediately from the private database.
